# Обновление адресов split-драйвера

Адаптация [Amnezia PR #3112](https://github.com/amnezia-vpn/amnezia-client/pull/3112) для SELFVPS, 09.10.2026.

Драйвер получает обновлённые адреса физического и VPN-интерфейсов после изменения маршрутов, интерфейсов или IP. Смена физического адаптера определяется по маршруту к серверу; при отсутствии маршрута используются доступные default routes с суммой метрик маршрута и интерфейса. VPN-интерфейс исключён из выбора физического default route. Неизменившаяся конфигурация повторно не отправляется.

Подписки устанавливаются до сбора стартовой конфигурации, чтобы не потерять изменение сети во время запуска. Уведомления Windows только ставят работу в очередь Qt; запросы к драйверу выполняются в потоке службы через существующий ограниченный по времени IOCTL. Новое событие обрабатывается через 250 мс; сбой или ожидание DAD дают не более трёх дополнительных попыток через секунду. После исчерпания попыток появляется предупреждение; очередное изменение сети позволяет повторить сбор адресов.

При остановке отменяются таймер и подписки, а номер поколения сессии меняется. Уже поставленные в очередь уведомления предыдущей сессии игнорируются. Отмена подписки с ошибкой сохраняет отключённый контекст callback вместо освобождения памяти, к которой Windows ещё может обратиться. Отложенные сообщения службе защищены QPointer и номером поколения. Quarantined handle после таймаута не получает новых IOCTL; сохраняется существующая явно предупреждающая политика службы для недоступного драйвера.

При исчезновении сети старые адреса обнуляются; при её восстановлении регистрируются новые. Tentative, loopback, multicast и link-local адреса не выбираются для обхода. IPv6 DAD не вызывает бесконечный таймер. При запуске по-прежнему требуется рабочая комбинация физических и VPN-адресов: READY во время DAD не выдаётся за успешно активированный обход.

Маршруты LAN и правила LAN/firewall этим изменением не переписываются. Подписанный драйвер не заменён. Экспериментальное восстановление отдельных CDN выключено (`AMNEZIA_EXPERIMENTAL_CDN_RECOVERY=OFF`).

## Проверка

Собраны Release-клиент и служба Qt 6.8.3 / MSVC. Шесть регрессий прошли:

- `split-tunnel-address-refresh` — настоящий start, сбор адресов, регистрация и монитор; смена IP из callback другого потока, неизменившиеся адреса, исчезновение/восстановление сети, IPv6/DAD, неправильный endpoint route, очередь после stop, старая сессия, ограниченные повторы, poisoned handle, частичный отказ подписки и неудачный старт.
- `network-driver-route-lifecycle` — остановка драйвера и жизненный цикл сети.
- `driver-failure-lifetime` — таймаут и время жизни буферов запроса.
- `exclusion-gateway-selection` — метрики и выбор физического шлюза.
- `lan-policy-transaction` — транзакция LAN-правил.
- `firewall-policy-transactions` — откат правил при ошибках.

В тесте адресов используется производственный код с заменёнными Windows API и вызовом IOCTL; реальные маршруты, драйвер и VPN не меняются. Эти проверки не доказывают устранение TLS-таймаута конкретного CDN Riot и не заменяют проверку после установки.

Проверочный установщик использует базовую версию 5.0.0.33 и отдельное имя `AmneziaVPN_5.0.0.33_x64_setup_address-refresh.exe`. Автоматической установки, публикации релиза и переключения рабочего VPN не выполнялось.
