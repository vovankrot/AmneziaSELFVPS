# SELFVPS 5.0.0.12

Изменения относительно последнего опубликованного релиза **5.0.0.6**. Включены накопленные доработки промежуточных сборок 5.0.0.7–5.0.0.12.

## Интерфейс и управление клиентами

- Настройки собраны в четыре понятных направления: **Общие**, **VPN и подключение**, **Серверы**, **Обслуживание**. Убрано дублирование раздела «Приложение». Настройки приложений, сайтов, DNS и Kill Switch доступны напрямую.
- Сохранены цвета, шрифты, карточки и оформление SELFVPS; исправлены размеры и области нажатия на небольших окнах.
- Вкладка клиентов загружает данные по SSH в фоне. Имена клиентов появляются раньше статистики и истории соединений, навигация остаётся доступной.
- Добавлены кнопка обновления списка и кеш на 30 секунд. Запросы выполняются последовательно, учитывается последняя выбранная пара сервер/протокол. Клиенты другого сервера не подмешиваются в список. После изменения клиентов кеш сбрасывается.
- Обратное DNS-разрешение истории XRay ограничено и выполняется параллельно. Недоступный DNS больше не задерживает интерфейс; без доменного имени показывается IP.
- Исправлен диалог доверия SSH: кнопки «Да» и «Нет» доступны даже при открытом индикаторе загрузки.
- Дополнены русская и английская локализации, включая настройки, управление сервером, обновления и новые элементы интерфейса.

## Обновления

- Клиент Windows проверяет новые релизы **vovankrot/AmneziaSELFVPS** при запуске и периодически, предлагает обновление и показывает описание изменений. Автоматическую проверку можно отключить.
- Проверка загружает метаданные. Загрузка установщика и запуск установки выполняются по действиям пользователя.
- Проверяются версия, адрес и состояние файла, размер и SHA-256 из GitHub Releases. Повреждённая или неполная загрузка не запускается.
- Обновление Hysteria на VPS получило проверку контрольной суммы, журнал выполнения, проверку запуска и откат при ошибке.

## Windows, драйвер и сетевое соединение

- В комплект включён подписанный драйвер раздельного туннелирования **Mullvad 1.3.0.0**, INF/CAT и сведения о происхождении. Установщик регистрирует каталог и проверяет состояние драйвера перед заменой.
- Исправлена инициализация современного API драйвера; старый API используется только при подтверждённой несовместимости. Ошибка или таймаут больше не запускает опасную повторную инициализацию.
- Исправлено принятие состояния **READY** после очистки правил: исправный драйвер больше не получает лишний RESET.
- Для установки конфигурации выделен отдельный бюджет ожидания. Отключение сохраняет короткий таймаут. После зависшего IOCTL дескриптор изолируется, буферы сохраняются до завершения операции, последующие вызовы на нём блокируются.
- Проверки здоровья XRay продолжаются после нескольких неудач, но больше не пересобирают маршруты и WFP посреди активных потоков. Повторяющиеся сообщения ограничены.
- Исправлена привязка TCP-сокетов к сетевому интерфейсу: учитывается реальное семейство IPv4/IPv6 и порядок байтов индекса. Для UDP сохраняется используемый маршрут к серверу; в журнале остаются реальные ошибки привязки.
- Усилены обработка аварийного закрытия и остановка дочерних процессов, убрано принудительное завершение потока VPN. Неприменённые настройки драйвера/защиты не выдаются за успешное подключение.

## Безопасность и совместимость

- SSH: проверка отпечатка сервера, подтверждение первого подключения и блокировка неожиданно изменившегося ключа.
- Hysteria и AnyTLS: проверка сертификата/pin без тихого отключения защиты. Для AnyTLS обновлены клиент, серверная сборка и сохранение сертификата.
- IPC: усилена проверка локального процесса и его исполняемого файла перед доступом к привилегированным операциям службы.
- Снимки конфигураций зашифрованы; перед восстановлением проверяются целостность, допустимые пути и конфигурация XRay. Добавлены проверяемая резервная копия, поэтапная замена и восстановление при ошибке запуска.
- Импорт различает версию приложения и формат конфигурации, сохраняет поддержку старого формата и отклоняет неизвестные версии.
- Списки доменов/IP и GeoIP проходят проверку размера и содержимого; ошибочная загрузка сохраняет предыдущий кеш.
- Исправлены разбор статистики `wg show` и передача дополнительных параметров AWG 3 на Android. Неподдерживаемые параметры AWG 3.1 отклоняются явно. **APK в этот релиз не включён.**
- Из журналов скрываются учётные данные в адресах прокси.

## VPS и установщик

- Новые контейнеры XRay/REALITY/Shadowsocks over XRay получают ограничения памяти и бюджет Go GC. Это не меняет автоматически существующие VPS.
- Добавлен отдельный административный сценарий для swap, лимитов памяти и ротации журналов. Он запускается вручную; установка клиента его не выполняет.
- Установщик использует резервную копию файлов и откат при неполном обновлении. Обрабатываются заблокированный драйвер, неудачная свежая установка и восстановление прежних файлов.
- Проверка SHA-256 и происхождения **54** поставляемых зависимостей выполняется перед упаковкой. Полная версия входит в имя установщика.

## Очистка проекта и проверки

- Убраны старые диагностические скрипты с локальными данными, журналы сборки и кеши IDE. Личная диагностика исключена из публикуемого дерева; сборочные файлы и готовые EXE не хранятся в Git.
- Добавлены документация структуры проекта, безопасный сценарий очистки, регрессионные тесты и GitHub Actions.
- Выполнена проверка текущих исходников, истории основной ветки, локальной диагностики и подмодулей на секреты. Добавлен Gitleaks в CI с отдельным правилом для простых паролей; сетевые дампы исключены из Git.
- Исправлен нестабильный тест повреждения снимка: теперь он гарантированно меняет исходный байт.
- Перед выпуском прошли проверки безопасности (12), обновления клиента (6), драйвера/привязки сокетов (2), интерфейса, фонового обновления клиентов, отката установщика, обновления Hysteria, манифеста и двух переводов.
- Windows Release собран; **422 файла** установочного пакета проверены. Клиент/служба совпадают с результатами сборки, зависимости — с манифестом.

## Известные ограничения

Таймаут видеосегментов Rutube в исключённом Firefox при работающем VPN **не объявлен устранённым**. Исправления драйвера, маршрутов и серверных ресурсов требуют проверки в реальной сети.

При исключении приложений строгий Kill Switch для соответствующих протоколов отключён; предупреждение сохранено, поскольку это действующая политика защиты.

Старые профили Hysteria/AnyTLS могут потребовать обновления сертификата/pin или повторного экспорта администратором VPS. Обновление Windows-клиента не обновляет автоматически серверы. Установщик SELFVPS не подписан Authenticode; подписи входящих драйверов проверяются отдельно.
