# Скриншоты SELFVPS

Четыре снимка предоставлены пользователем 1 октября 2026 года: главная, клиенты, установщик 5.0.0.12 и Build Studio.

- `home.png`: IP сервера закрыт непрозрачной плашкой.
- `clients.png`: дата активности закрыта непрозрачной плашкой.
- `installer.png` и `build-studio.png`: изображение сохранено без изменения видимых элементов.

Разрешение оригиналов сохранено. PNG пересохранены без метаданных; сравнение пикселей подтвердило отсутствие изменений за пределами двух закрытых областей. Генеративные изображения и снимки тестового интерфейса в галерее не используются.

Перед заменой снимков проверяйте IP и домены серверов, имена пользователей, пути с именем учётной записи, ключи, QR-коды, конфигурации и историю активности. В репозиторий добавляются только подготовленные публичные изображения. Старые снимки удалены из текущего дерева; прежние версии могут оставаться в истории Git.
